# Share one session runtime across entrypoints

Interactive terminal, fullscreen and classic renderers, print mode, evaluation adapters, and the legacy development entrypoint construct and close the same `SessionRuntime`, which owns configuration, LLM, MCP, policy, sandbox, context, memory, loop control, tasks, and session persistence. UI layers consume runtime events and do not assemble agent dependencies. Explicit capability profiles replace ad hoc bare-mode omissions, and every launch emits a machine-readable activation manifest, preventing an entrypoint from appearing equivalent while silently running a smaller agent stack.
