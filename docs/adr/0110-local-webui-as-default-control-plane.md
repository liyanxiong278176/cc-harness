# ADR 0110: Use a local WebUI as the default control plane

The installed `cc-harness` command starts a loopback-only FastAPI/React WebUI by default and keeps `--tui` as an explicit compatibility surface; the WebUI talks to the existing Durable Runtime through REST for commands and replayable Server-Sent Events for live updates, so browser disconnects do not cancel runs and Ctrl+C remains the process-wide graceful shutdown boundary. A project folder is selected before a user turn can be submitted, each project keeps its own Runtime store and supervisor lease, settings are persisted in the existing user configuration layer, and no prompt, hidden reasoning, or API key is emitted in events. This deliberately avoids a second execution engine and avoids WebSockets in v1: REST/SSE are simpler to reconnect and audit against the event log, while a loopback default limits exposure; remote access and authentication remain future decisions.
