# Gate cutover on capability continuity

Durable cutover requires non-compensating activation, artifact, recovery and regression evidence for production context compaction, offload and continuation, Run-history recall, memory services, safety and provenance, native/command/MCP Tool Observations, PlanGraph scheduling, child integration, follow-up handoff and legacy data migration. Retained source code, a runnable simplified Loop, or an aggregate green test result cannot compensate for one unwired capability, and the prior runtime remains a rollback path until every gate passes.
