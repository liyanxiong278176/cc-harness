# Gate the agent runtime rebuild with non-compensating evidence

The clean runtime cutover will occur only after all non-compensating migration, crash-recovery, unknown-outcome, lease-fencing, worktree-isolation, evidence-completion, offline-approval, credential-isolation, follow-up-queue, stall, cross-platform, rollback and frozen-parity gates pass. Coding quality or performance gains cannot offset data loss, unsafe replay, permission bypass or unrecoverable migration, because the rebuild replaces the old runtime in one controlled release.
