# Mirror the Claude Code classic shell with cc-harness branding

cc-harness treats Claude Code's classic inline renderer as its character-grid reference for the startup panel, framed prompt, and layered status area, while retaining its own name, version, instructions, release notes, and an original Yuexin Cat pixel mascot. A loose "terminal-inspired" design was rejected because it leaves spacing and state hierarchy ambiguous; copying Claude branding was rejected because it would misrepresent product identity.
