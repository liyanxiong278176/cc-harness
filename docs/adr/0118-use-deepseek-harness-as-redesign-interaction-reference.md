# ADR-0118：以 DeepSeek Harness 为整体交互参考重设计 WebUI

状态：Accepted；日期：2026-10-23。整体访谈已收口，用户确认共识并授权实施；2026-10-24 完成实施验证收尾。

用户在本机实机观察后，确认以 DeepSeek Harness 的整体信息架构与任务执行展示作为新一轮 WebUI 重设计基线，取代仅改造执行展示或继续以 Claude Desktop 为主的方向。cc-harness 使用自有字体、比例、色彩和品牌，既有 Runtime 事实仍是展示依据。

本决定取代 ADR-0113 中的主要参考产品选择；不将其余尚未讨论的交互规则自动视为废止，也不恢复 ADR-0111 的 vendor 快照方案。布局细节、默认过程展示密度、轨迹页范围与验收标准将在后续访谈逐项确认。

实测证据与范围限制见[观察记录](../design/2026-10-23-deepseek-harness-redesign-discovery.md)。

后续确认范围：任务文件变更摘要与右侧差异查看纳入本轮，允许补齐可靠差异所需的数据支持；因此 ADR-0113 中“后端仅增加产物查询与当前文件预览”的范围限制不再约束此项能力。差异证据实现方案尚未确定，项目产物当前文件预览的定义保持独立。
