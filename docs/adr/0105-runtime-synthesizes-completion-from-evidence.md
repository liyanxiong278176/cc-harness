# ADR 0105: Let the Runtime synthesize completion from verified evidence

The Durable Runtime, rather than the model's final prose or completion marker, is authoritative for task completion. After a model response or other progress signal, the Runtime evaluates the pinned Goal Contract: acceptance criteria coverage, required verifier results, required artifacts, managed-process readiness, child-task/approval gates, and absence of unresolved or unknown outcomes. When the gate passes it emits an auditable synthesized completion candidate and accepts the plan node/run; when it does not pass, it keeps the run active or blocked with structured missing-evidence reasons. A model completion marker remains an optional request to run the gate, never a prerequisite or sufficient proof.
