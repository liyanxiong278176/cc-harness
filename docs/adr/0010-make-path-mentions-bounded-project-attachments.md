# Make path mentions bounded project attachments

An `@path` mention resolves to a real, redacted attachment for the current turn: text files contribute bounded snapshots and directories contribute indexes rather than recursive contents. Supported images may also enter through `@path`, a dragged terminal path, or `Alt+V` clipboard import; validated images are copied into private session attachment storage so resumed multimodal context does not depend on the original path, and are removed with their session. Completion excludes repository metadata, dependency environments, likely secret files, and unsupported binaries by default, while paths outside the project require explicit confirmation; providers that reject vision input surface an explicit error rather than silently discarding the image.
