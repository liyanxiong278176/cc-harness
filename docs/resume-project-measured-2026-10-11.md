# 长链路编程 Agent 运行框架（cc-harness）

**项目背景：** 面向长链路编程任务构建 Agent Runtime，支持状态恢复、上下文压缩、跨会话记忆检索及工具调用安全控制，并基于自建代码修复、历史配置查询和故障注入场景进行内部对照实测。

- **任务状态恢复：** 基于 Run 状态、事件存储与 Checkpoint 实现持久化恢复；在 12 次真实进程异常退出实验中，已提交状态均成功恢复，状态加载中位耗时 10.1 ms；通过语义去重，在 20 批重复动作测试中拦截 40 次多余分派。
- **上下文管理：** 设计 Snip、Prune、Summary 三级压缩机制，保留系统指令与近期任务信息，并保留历史原文用于回查；在 12 组大工具输出与代码修复对照中，计入摘要生成后的总 Token 用量减少 63.9%，压缩前后代码断言均为 12/12 通过。
- **跨会话记忆：** 构建 L1 事实、L2 场景、L3 用户画像架构及分层检索链路；在自建的 24 条历史偏好、预约规则和设备配置查询中取得 83.3% 回答准确率，相较完整历史注入减少 90.2% 查询输入 Token，并通过失败样例定位场景检索提前停止的问题。
- **工具调用安全：** 构建权限决策、非可信内容来源校验和输出 DLP；在内部验证中拦截 28/28 条越界及非可信内容诱导请求，将 30 条模拟 API key 输出样例中的未脱敏泄露由 30 条降至 0 条。

上述数据均来自内部构造场景。记忆完整历史对照准确率为 24/24，分层查询为 20/24；Summary 单档在单轮实验中增加输入开销，综合三档总 Token 才减少 63.9%。面试时应明确这些取舍，不将结果表述为线上业务效果、历史版本提升或完整 Agent 任务成功率提升。

详细口径及证据见 [内部对照实测报告](eval/resume-ablation-2026-10-11.md)。
