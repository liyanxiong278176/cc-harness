# 简历指标内部对照实测（2026-10-11）

本报告使用当前工作区代码、自建隔离样例和真实模型调用，未使用第三方测评题库。结果属于工程功能消融验证，不是线上用户数据、历史版本对比或完整编程 Agent 的端到端任务成功率。

## 测量设置

- 项目：当前 `cc-harness` 工作区；使用运行时、压缩、记忆、权限和 DLP 的真实实现。既有工作区改动保留，未改动产品实现以改善成绩。
- 模型请求名：`deepseek-v4-flash`；Provider 响应名：`deepseek-flash`。温度为 0，thinking 关闭，单次最大输出 1,800 tokens，自动 API 重试关闭。
- 共 100 次有记录的真实 API 调用：24 次代码修复、4 次压缩摘要、72 次历史查询。API 报告总用量 358,336 tokens。另一次准备阶段 READY 连通性检查不计入实验。
- 结果共 316 条，`domain + case + condition` 唯一；没有把失败样例丢弃。实验组调用顺序按固定种子打乱。
- Token 主指标使用 Provider 返回的 `usage`。本地 `cl100k_base` 估算用于选择压缩档位，并非 Provider 精确分词器。
- 压缩窗口为压力实验设置，按原始本地 Token 用量和 0.70/0.88/0.98 的占用比计算；近期保护区为 80 tokens。这不是项目默认窗口或默认保护区，不可推广为生产默认效果。
- 工具日志由真实 Python 子进程执行生成，包含 350 或 650 条预约导入记录和 buggy helper 的检查输出；完整修复规格位于受保护的最新用户消息中。日志属于构造的应用样例，不是线上业务日志。
- L1 使用真实 SQLite/sqlite-vec 存储与 `MemoryRetriever`；embedding 是项目提供的 128 维本地词法哈希实现，不是语义 embedding 服务。L2/L3 文本和 L1 事实提前写入，库关闭后重新打开再检索；未测自动记忆提取或自动画像生成质量。
- 恢复耗时包含 RunStore 打开和 projection 读取，不包含操作系统启动、Python 进程启动或模型推理。恢复对象是已提交的 queued Run 及其目标、计划和状态，不是执行中代码任务的完成结果。
- 重复动作使用生产 worker 的同批去重选择函数，再由实验执行器向本地 ledger 记录实际选中的动作；未验证跨批去重、外部服务副作用或崩溃后的 exactly-once 语义。
- 权限实验调用真实 `PolicyEngine`，但未执行外传等攻击动作；未测试模型是否会提出攻击动作，因此不能称为 Agent 整体攻击成功率。

## 失败与取舍

### 1. 四条 L2 场景查询提前停在 L3

画像包含 `scenario_ids: booking-v0001`。查询 `Booking rules slot_minutes` 等规则时，当前 `_matches` 只需任意查询词出现在候选文本中就认定命中。`booking` 在画像引用 ID 中出现，使 progressive 检索提前返回 L3，不再读取 L2 的实际规则。模型正确回答 UNKNOWN，四条查询均失败。

分层结果按层拆分：L3 为 4/4，L2 为 0/4，L1 为 16/16。完整历史对照为 24/24，说明失败来自检索阶段缺少证据，不能用“模型没回答好”解释。产品代码未在本次实测中修补，83.3% 保留这四条失败。后续可以用“是否包含可回答的事实”作为继续检索条件，并用本组用例回归。

### 2. Summary 单轮成本并未下降

| 压缩档位 | 样例数 | 完整历史输入 | 压缩后修复输入 | 摘要辅助输入 | 本轮累计输入变化 |
| --- | --- | --- | --- | --- | --- |
| Snip | 4 | 76,752 | 2,142 | 0 | 减少 97.2% |
| Prune | 4 | 76,754 | 1,335 | 0 | 减少 98.3% |
| Summary | 4 | 76,698 | 1,621 | 77,152 | 增加 2.7% |

Summary 的摘要输入与完整历史规模接近；只做一次后续修复请求时，摘要开销尚未摊薄。综合三档才得到累计输入减少 64.3%、总 Token 减少 63.9%。不能把 97.8% 的最终请求压缩率写成“总模型成本节省 97.8%”，也不能宣称每一档都降低单轮成本。

### 3. 没有测出的指标

本次没有得出线上任务完成率提升、最大连续对话轮次提升、真实用户重复解释次数下降、生产泄露率下降、完整编程 Agent 的任务完成耗时改善。这些需要真实任务集和完整 Agent 执行链的配对实验，不能由上述功能样例推算。

### 4. 样本规模

12/12 只是本组样例全部成功，二项比例的 95% Wilson 区间约为 75.8%–100%；记忆 20/24 的区间约为 64.2%–93.3%。样例由本项目构造，区间也不能消除样例代表性限制。简历优先写样本数和实测条件，避免声称任意场景均达到 100%。
