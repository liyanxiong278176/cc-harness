# V11 对照测试中断记录

该轮计划 100 个任务、每组每题三次执行，共 600 次。接口余额不足返回 HTTP 402 后停止。原始 588 条任务记录、454 条失败请求及未完成执行目录均保留在 `eval/result/context-quality-formal-2026-10-11/`，不能将接口失败当作压缩质量失败，也不能声称该轮完整结束。

不含接口错误且六次执行均完成的 21 个任务全部属于 numeric 类；关闭与开启各通过 63/63。对应总 Token 为 1,431,501 和 1,065,820，减少 25.5%。这只是中断前的数字类前缀，不代表完整任务集。

后续审查发现该轮 Summary 实际触发次数和辅助摘要调用均为零。证据预览在压力判断之前被缩短，使本应进入 Summary 的历史绕过该档位。因此即使 `stopped.json` 的部分样本计算字段显示观察值目标满足，也不能据此证明三级压缩整体满足目标；该字段没有核查三档实际覆盖。

V12 修正压力判断顺序，新增对应回归用例，并在独立目录重新执行两组全部测试。新旧轮次不会混合统计，旧失败记录不会被覆盖。正式报告额外要求三档均有实际触发、存在真实摘要调用，并检查完整任务计划与接口错误。
